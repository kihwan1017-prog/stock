# 사용자 매뉴얼 (User Web)

**대상:** 일반 회원 · 트레이더 (브라우저 **User Web**)  
**제품 이름:** KIKI Trade  
**화면 주소(기본값):** http://localhost:3000/user/dashboard

이 문서는 **회원용 화면(`/user/...`)** 을 쓰는 순서대로 안내합니다.  
관리자 전용 화면(`/admin/...`)은 [관리자매뉴얼.md](관리자매뉴얼.md) · Admin 메뉴를 보세요.

> **꼭 알아두세요**  
> - 로그인은 **아이디·비밀번호(JWT)** 입니다.  
> - 기본 매매는 **Paper(모의)** 입니다. 실전(LIVE)은 막혀 있거나 관리자 승인 후에만 가능합니다.  
> - 메뉴는 **역할(viewer / trader / admin)** 에 따라 일부만 보입니다.  
> - Kill Switch가 켜져 있으면 **신규 주문이 막힐 수** 있습니다. 해제는 관리자만 가능합니다.

## 1. 이 화면이 뭔가요?

User Web은 **내 계좌·모의매매·포트폴리오·관심종목·뉴스/공시·AI 참고 추천**을  
브라우저에서 쓰는 회원용 콘솔입니다.

```text
내 브라우저 (User Web)
        ↓  JWT 로그인
   서버(API)  ←→  데이터베이스
        ↓
  시세·Paper 주문 · (선택) AI / 뉴스 / 공시
```

| 구분 | 주소(기본) | 누가 쓰나 |
|------|------------|-----------|
| User Web | http://localhost:3000/user/... | 일반 회원 |
| Admin | http://localhost:3000/admin/... | 관리자·운영 |
| API 서버 | http://127.0.0.1:8000 | 백엔드 |
| 건강 점검 | http://127.0.0.1:8000/health | 서버 살아 있는지 |

설치·서버 기동은 [설치매뉴얼.md](설치매뉴얼.md) · [운영매뉴얼.md](운영매뉴얼.md) 를 보세요.

## 2. 쓰기 전에

1. 서버(백엔드)가 켜져 있어야 합니다.  
2. 프론트(Next.js)가 켜져 있어야 합니다.  
3. 관리자가 계정을 만들어 줬거나, **회원가입**이 열려 있어야 합니다.

확인: 브라우저에서 http://127.0.0.1:8000/health → 상태 정보가 보이면 서버는 정상입니다.

## 3. 회원가입 · 로그인

### 3-1. 로그인

1. http://localhost:3000/login 을 엽니다.  
2. 아이디·비밀번호를 입력하고 로그인합니다.  
3. 성공하면 Access/Refresh 토큰이 **세션(탭)** 에 저장되고, User 또는 Admin 화면으로 이동합니다.

> 보안: 토큰은 **sessionStorage**(+ 보조 쿠키)만 사용합니다. Remember Me(영구 저장)는 없습니다.  
> 브라우저 탭을 모두 닫으면 다시 로그인해야 할 수 있습니다.

### 3-2. 회원가입

1. http://localhost:3000/signup  
2. 안내된 항목(아이디·이메일·비밀번호·약관 등)을 채웁니다.  
3. 가입 후 로그인합니다.  
4. **매매·자동매매** 메뉴가 안 보이면 관리자에게 **trader 역할**을 요청하세요.

### 3-3. 로그아웃

화면 상단(또는 내 정보)에서 로그아웃하면 토큰이 지워집니다.

## 4. 처음 한 번 할 일 (추천 순서)

| 순서 | 메뉴 | 할 일 |
|------|------|--------|
| 1 | **내 계좌** | Paper 계좌 생성 (모의 예수금) |
| 2 | **설정** | 기본 Paper 계좌·테마·알림 기본값 확인 |
| 3 | **관심종목** | 자주 볼 종목 추가 (뉴스·공시·AI의 기준) |
| 4 | **Dashboard** | 자산·보유·최근 주문 요약 확인 |
| 5 | **매매** | Paper 모드로 소량 연습 주문 |
| 6 | **포트폴리오** | 보유·비중·수익률 확인 |

실전 주문·키움 LIVE는 **이 매뉴얼 범위 밖**입니다. 관리자·[LIVE 체크리스트](../trading/LIVE_TRADING_CHECKLIST.md)를 따르세요.

## 6. 화면별 사용법

### 6-1. Dashboard

- **총 자산 · 평가/실현 손익 · 일일 수익률** 등 KPI  
- 보유 종목 · 실행 중 전략 · 최근 주문/체결  
- AI 추천·뉴스·공시 요약 카드 (관심/보유 종목 기준)  
- 기본 Paper 계좌는 **내 계좌/설정**에서 정한 계좌를 사용합니다.

계좌가 없으면 KPI가 비거나 오류가 납니다 → 먼저 **내 계좌**에서 Paper를 만드세요.

### 6-2. 내 계좌

- **Paper 계좌 생성:** 모의 예수금으로 연습용 계좌를 만듭니다.  
- **Broker 계좌 연결:** 소유권 매핑만 관리합니다. (실계좌 번호·Secret은 화면에 저장·표시하지 않습니다.)  
- 계좌를 골라 **Paper 포지션**을 확인할 수 있습니다.

### 6-3. 매매 (trader)

1. 모드를 **PAPER**로 둡니다. (연습)  
2. 종목·현재가를 확인합니다.  
3. 매수/매도 · 지정가/시장가 · 수량·가격을 입력하고 제출합니다.  
4. **미체결**에서 취소, **체결**에서 결과 확인합니다.

주의:

- **Kill Switch ACTIVE**면 주문이 거부될 수 있습니다.  
- **LIVE**는 실제 주문 경로입니다. Risk·Kill Switch가 강제됩니다. 함부로 켜지 마세요.  
- 실시간 시세 스트림 UI는 일부 **준비 중**일 수 있습니다.

### 6-4. 자동매매 (trader)

- 자동매매 **ON/OFF** · 실행 중 전략 · 세션 단계  
- Kill Switch **상태 조회** (해제는 Admin)  
- 위험관리·실행 로그 확인  

일부 예약/고급 항목은 화면에 “준비 중” 안내가 있을 수 있습니다.

### 6-5. 전략 · 백테스트 (trader)

- 전략 목록에서 생성·수정·실행·중지  
- 이동평균 백테스트 · Walk Forward 결과 확인  
- 전략 **삭제**·포트폴리오 최적화 일부는 API/화면에 없을 수 있습니다 (안내 배너 참고)

### 6-6. 포트폴리오 · 거래내역

- 포트폴리오: 보유 비중·종목별 수익률·거래·자산 이력  
- 거래내역: **계좌를 선택한 뒤** 주문/체결을 조회합니다.

### 6-7. 관심종목 · 뉴스 · 공시 · AI

| 화면 | 핵심 |
|------|------|
| 관심종목 | 종목 검색 후 추가/삭제. 뉴스·공시·AI의 입력 |
| 뉴스 | 관심종목 뉴스 목록·원문. **뉴스 AI 요약은 준비 중**일 수 있음 |
| 공시 | 관심종목(KRX) DART 공시 조회 · **공시 AI 요약 요청** |
| AI 추천 | 관심/보유 기반 **참고용** 추천. **이 화면에서 주문이 나가지 않음** |

### 6-8. 알림 · 설정 · 내 정보

- **알림:** 읽음/보관 · 이벤트 구독 (Telegram은 구독 설정 경유)  
- **설정:** 테마(Light/Dark) · 언어 · 기본 계좌 · AI/알림 선호  
- **내 정보:** 프로필 · 비밀번호 변경 · 로그인 세션 · 연결 계정 요약

| 역할 | 대략적인 범위 |
|------|----------------|
| viewer | 조회 중심 (대시보드·포트폴리오·뉴스 등) |
| trader | viewer + **매매 · 자동매매 · 전략 · 백테스트** |

1. http://127.0.0.1:8000/health 확인  
2. 브라우저 새로고침 · 다시 로그인  
3. Paper 계좌·관심종목이 있는지 확인  
4. Kill Switch / LIVE 모드인지 확인  
5. 그래도 안 되면 [장애대응매뉴얼.md](장애대응매뉴얼.md) · [FAQ.md](FAQ.md)

로그인 직후 보호 페이지로 못 들어가면: 쿠키/세션이 비어 있는 경우입니다. 다시 로그인해 보세요.

## 10. 자주 묻는 질문

**Q. Admin이랑 User가 뭐가 달라요?**  
A. User는 **내 투자·모의매매**용, Admin은 **회원·동기화·리스크·운영**용입니다.

**Q. 주문이 계속 거절돼요.**  
A. Kill Switch, 권한(`trading:write`), Paper 계좌 소유권, LIVE 미승인 등을 확인하세요. 거부 사유 코드가 뜨면 그 메시지를 관리자에게 전달하세요.

**Q. AI 추천을 누르면 자동으로 사나요?**  
A. 아니요. AI 화면은 **참고용**이며 주문을 실행하지 않습니다.

**Q. 실전으로 사고팔고 싶어요.**  
A. 기본은 막혀 있습니다. 관리자·운영 체크리스트·LIVE 이중 게이트를 반드시 따르세요.

**Q. 토큰이 어디 저장되나요?**  
A. 브라우저 **세션 저장소**입니다. 공용 PC에서는 사용 후 로그아웃하세요.

더 많은 질문 → [FAQ.md](FAQ.md)
